Control de Versiones | Git & GitHub

BIENVENIDO A INS-600

Aprendiendo Git y GitHub para gestionar, versionar y colaborar en proyectos de software de una manera profesional, ordenada y eficiente.

Comenzar a aprender Conocer GitHub
Git Sistema de control de versiones distribuido
GitHub Plataforma para alojar y colaborar en repositorios
Trabajo Colaborativo Flujos de trabajo profesionales para equipos
Propósito del curso

Objetivos de Aprendizaje

Al finalizar este espacio práctico, seremos capaces de aplicar buenas prácticas con Git y GitHub en el desarrollo de proyectos reales.

Comprender el Control de Versiones

Identificar la importancia del versionado, sus ventajas y cómo Git soluciona el seguimiento de cambios en el código fuente.

Dominar Comandos Fundamentales

Aprender a inicializar, agregar, confirmar, vincular y sincronizar repositorios utilizando la línea de comandos.

Colaborar con GitHub

Utilizar repositorios remotos, ramas, y el flujo de trabajo colaborativo para integrar cambios entre integrantes del equipo.

Ruta de Aprendizaje

Contenido Práctico

Temario desarrollado paso a paso con ejercicios prácticos para afianzar cada comando.

Módulo 1

Fundamentos de Git

Introducción al sistema de control de versiones y configuración inicial del entorno de trabajo.

  • ¿Qué es Git?

    Conceptos, historia, ventajas y diferencias con otros sistemas.

  • Inicialización de repositorio

    git init - Creando nuestro primer repositorio local.

  • Seguimiento de archivos

    git add, git status y área de staging.

  • Confirmación de cambios

    git commit -m "mensaje" y buenas prácticas en mensajes.

Módulo 2

GitHub y Colaboración

Conexión con repositorios remotos, sincronización y trabajo en equipo.

  • Creación de repositorio remoto

    Configuración y vinculación entre local y remoto.

  • Conexión con origen

    git remote add origin <URL_DEL_REPOSITORIO>

  • Subida de cambios

    git push - Sincronizando nuestro código con GitHub.

  • Descarga y actualización

    git pull, git clone y resolución básica de conflictos.
